# Product Requirements Document

The PRD is the authoritative spec for AetherBus. Living source:

- [PRD_AetherBus.md on GitHub](https://github.com/ShazebA/aetherbus/blob/main/PRD_AetherBus.md)
- Raw copy at the repo root

!!! note "Why isn't it embedded here?"
    The PRD is large (~40 KB) and frequently linked from PRs and ADRs by section number (e.g. "PRD §6.7"). Keeping a single canonical copy at the repo root means every internal cross-reference resolves identically whether you're reading on GitHub, in your editor, or via this docs site.
